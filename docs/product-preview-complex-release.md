# Предпросмотр продукта сложная

Продолжение ветки `предпросмотер` (69a63bf) с актуальным `origin/main` (83fded5). Включены три ещё не влитых коммита исходной ветки: редактор с живым предпросмотром, приватные продукты и описание/рейтинг витрины.

## Поведение

- Одно описание продукта; пустой предпросмотр показывает «Описание продукта». Старое поле headline используется на публичной странице только при отсутствии description. При редактировании его текст переносится в единое поле, которое можно полностью очистить.
- На компьютере и телефоне одна прокручиваемая колонка, обложка 16:9 с ограничением высоты 360 px, без правой карточки покупки. Компьютерный iframe использует ширину 1024 px вместо 1280 px, чтобы увеличить содержимое.
- Назад и продавец с аватаром расположены вместе сверху. На телефоне у Назад только стрелка; на компьютере она левее обложки. В редакторском iframe переходы и покупка не выполняются.
- Одна нижняя панель цены/покупки на всех экранах. Выбранный тариф управляет ценой, пробным периодом и option в checkout. Контент получает отступ по измеренной высоте панели.
- Без отзывов — «Тут будут отзывы». Внизу Пожаловаться красным без рамки, справа Поделиться.
- Витрина: имя, одна жёлтая звезда, рейтинг и число отзывов либо (0 отзывов), затем описание. Автоматические тип профиля, дата регистрации и продажи убраны. Кнопка справа делится URL витрины.
- Описание продавца в настройках под именем, для автора и школы; чтение и сохранение явно передают текущий profileId.
- Разово переименовано в Навсегда в редакторе вариантов и покупательском выборе. Оплата/банк/карта и сохранение реквизитов при выходе сохранены из main.
- Вопрос про положение полосы прокрутки рядом с крестиком не входит в доработку.

## Supabase

Перед интеграционной проверкой применить `20261105092358_product_preview_storefront.sql`, затем опубликовать `manage-profile` с обновлённым `_shared/profiles.ts`. Vercel публикует клиент, SQL и функции этим не обновляются.

Старая неприменённая миграция исходной ветки `20260917120000_private_products_and_seller_metrics.sql` перенесена в новую: её номер совпадал с уже существующей в main `20260917120000_product_marketplace_visibility.sql`. Старую миграцию предпросмотра отдельно не применять. Миграция main сохранена.

Доступность is_active отделена от публикации is_published. Новые товары доступны по ссылке и не выставляются автоматически на витрину. Существующие флаги товаров не переписываются. Старые описания длиннее 500 символов не препятствуют миграции; лимит проверяется при последующих записях.

Рейтинг агрегируется по всем товарам продавца; список публичных товаров берётся из public_products и не раскрывает приватные товары.

Общая/рабочая база, секреты и AWS в ходе этой задачи не изменялись. Реальная интеграция с Supabase требует доступа к целевому проекту.

## Проверка

- Production build, Vitest и отдельные Node test suites.
- Проверка типов: остаются 7 ошибок main в CreatorUsersTab/ScheduleTab/SlotCreationWizard; эти файлы совпадают с main.
- ESLint изменённых страницы продукта/витрины и вспомогательных модулей — без ошибок. В большом унаследованном редакторе есть прежние lint-замечания.
- manage-profile проходит Deno check. manage-products совпадает с main и содержит прежние ошибки типов Caller/SubscriptionStatus.
- Миграция выполнена в изолированном PostgreSQL/PGlite: средний рейтинг и число отзывов, фильтрация приватного товара, доступ к публичному RPC для anon, значения по умолчанию и старое длинное описание.
- Реальные компоненты с локальным тестовым API при 1280×900, 390×844 и 320×740: iframe на компьютере/телефоне, прокрутка длинного текста, единый placeholder, несколько тарифов и пробный период, описание в настройках, витрина с отзывами и без.
- Мобильная проверка выполнена в браузерном viewport; физические iOS/Android устройства не использовались.

Временная демонстрация, логи, снимки экрана, локальные SQL-проверки и .env исключены из PR.
