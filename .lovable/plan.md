## Цель

На странице продукта (`/product/:id`) изменить отображение верхней медиа-области в зависимости от того, что загрузил автор:

1. **Только картинка** — показывать чистую картинку сверху описания, без затемняющего градиента снизу.
2. **Картинка + видео** — показывать картинку как обложку (постер) видео с заметной круглой кнопкой Play по центру. По нажатию Play — запускается воспроизведение видео прямо в той же области (со штатными контролами).
3. **Только видео без картинки** — поведение как сейчас (видео с дефолтным постером).

## Что меняется

Файл: `src/pages/ProductPage.tsx`, блок «Hero Media» (строки ~59–80).

Новая логика рендера:

- `videoUrl && imageUrl` → состояние `isPlaying` (useState, по умолчанию false):
  - Если `!isPlaying`: рендерим `<img>` на всю область + полупрозрачный оверлей с большой круглой кнопкой Play по центру (иконка `Play` из lucide-react). Клик по кнопке → `setIsPlaying(true)`.
  - Если `isPlaying`: рендерим `<video>` с `autoPlay`, `controls`, `playsInline`, `poster={imageUrl}`.
- `videoUrl && !imageUrl` → `<video controls playsInline preload="metadata">` (как сейчас, без постера).
- `!videoUrl && imageUrl` → чистый `<img>` без градиентного оверлея.
- Ни того, ни другого → fallback `heroBackground` без оверлея.

Кнопка Play: круг ~72px, фон `bg-background/80 backdrop-blur`, иконка `Play` размер 32, hover-scale, центрируется через `absolute inset-0 flex items-center justify-center`.

Никаких изменений в редакторе продукта, в БД, в логике загрузки и в других компонентах. Только презентационный слой `ProductPage.tsx`.
