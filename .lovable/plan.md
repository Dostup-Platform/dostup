Убрать кнопку «Учителя» и связанный с ней функционал из режима автора курса (Creator Dashboard → Продукты).

### Что убирается
1. В `src/components/creator/CreatorProductsTab.tsx`:
   - Убрать импорт `ProductTeachersManager`.
   - Убрать состояние `teachersProduct` / `setTeachersProduct`.
   - Убрать кнопку «Учителя» (и иконку `Users` из actions карточки продукта).
   - Убрать рендер `<ProductTeachersManager />` внизу компонента.
   - Убрать `Users` из импорта `lucide-react`, если больше нигде не используется.

2. Компонент `ProductTeachersManager` остаётся в кодовой базе — он будет использоваться позже в режиме «онлайн-школа».

### Что НЕ трогается
- Логика расписания в `CreatorScheduleTab` (создатель продолжает управлять слотами напрямую, `teacher_id = null`).
- Логика покупок и назначения учителей в `CreatorUsersTab`.
- Бэкенд (таблицы, edge-функции, hooks для учителей).

После изменений автор курса больше не видит и не может открывать управление учителями со страницы продуктов.
