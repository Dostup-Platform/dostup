## Прямая загрузка в S3 через presigned URL — ВЫПОЛНЕНО

### Что сделано
1. **Новая Edge Function `s3-presign-upload`** — генерирует presigned PUT URL для прямой загрузки в S3
2. **Обновлён `uploadFileToS3`** — теперь загружает файлы напрямую в S3 через браузер (без лимитов Edge Function)
3. **Прогресс-бар загрузки** — добавлен в оба менеджера материалов (creator и teacher)
4. **Поддержка файлов до 5 ГБ** — без ограничений Edge Function по памяти

### Важно
CORS на S3 бакете должен разрешать PUT-запросы с доменов приложения.
