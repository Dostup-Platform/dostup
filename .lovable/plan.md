## Изменения в `src/components/creator/CreatorMaterialsTab.tsx`

1. **Убрать авто-открытие менеджера.** В `useEffect` больше не вызывать `setManagerOpen(true)` — выставлять только `selectedId`. При смене продукта через `ProductSwitcher` тоже не открывать менеджер, только обновлять `selectedId`.

2. **Переименовать кнопку.** Справа сверху кнопка `«Управлять материалами» / "Материалдарды басқару"` → `«Добавить материалы» / "Материал қосу"` (иконка `Plus` остаётся). По клику открывается тот же `ProductMaterialsManager` (диалог), который уже умеет создавать материалы.

3. **Показать материалы продукта снизу.** Под строкой с `ProductSwitcher` + кнопкой добавить блок-список материалов выбранного продукта:
   - Использовать существующий хук `useProductMaterials(selectedId, { creatorOnly: true })` из `src/hooks/useMaterials.ts`.
   - Состояние загрузки — спиннер; пустой список — короткий текст «Материалов пока нет» (ru/kk).
   - Каждый материал — карточка (`Card` + `CardContent`) с иконкой по типу (`Folder` для `folder`, `LinkIcon` для `link`, `Type` для `text`, `FileText` для `file`/`video`), названием и небольшой подписью с типом. Только просмотр, без действий редактирования — управление остаётся внутри диалога менеджера, который открывается по кнопке «Добавить материалы».
   - Показывать только корневые элементы (`parent_id == null`), чтобы не дублировать содержимое папок.
   - Клик по карточке — открывает менеджер материалов (`setManagerOpen(true)`), внутри которого пользователь уже может перейти в папку/отредактировать.

4. **Поведение после закрытия диалога.** Когда `ProductMaterialsManager` закрывается (`onClose`), список материалов снизу автоматически обновится (React Query инвалидация уже есть в хуках create/update/delete) — дополнительных действий не требуется.
