

## Проблема
Формы добавления материалов (у автора и учителя) позволяют добавлять только **файлы** и **папки**. Хотя база данных уже поддерживает типы `text`, `link`, `video` — в интерфейсе нет возможности их создать.

## Решение

Расширить `ItemType` и формы в обоих компонентах, добавив варианты "Ссылка" и "Текст".

### 1. `src/components/creator/ProductMaterialsManager.tsx`

- Расширить `ItemType`: `"file" | "folder" | "link" | "text"`
- Добавить в `FormData` поля `content` (для текста) и `linkUrl` (для ссылки)
- В `RadioGroup` добавить 2 новых варианта: Ссылка (LinkIcon) и Текст (Type icon)
- Для типа "link": показать поля "Название" + "URL ссылки"
- Для типа "text": показать поля "Название" + textarea для контента
- В `handleAdd`: для link/text — вызывать `createMaterial` без загрузки файла:
  - link: `type: "link"`, `file_url: linkUrl`, `content: null`
  - text: `type: "text"`, `content: textContent`, `file_url: null`
- Оба типа поддерживают `parent_id` (т.е. можно добавлять внутри папки)
- Убрать обязательность файлов для этих типов

### 2. `src/components/teacher/TeacherMaterialsManager.tsx`

- Аналогичные изменения: расширить `ItemType`, добавить поля в форму, добавить RadioGroup опции, обработать в `handleAdd`

### 3. Для папки: при itemType === "folder"

- Добавить секцию "Ссылки и тексты в папку" аналогично файлам (опционально, пользователь может добавить их потом, зайдя внутрь папки) — проще всего оставить как есть: пользователь создаёт папку, заходит внутрь, и там добавляет ссылки/тексты/файлы

Никаких изменений в БД не требуется — все типы уже есть в enum `material_type`.
