

# Динамические превью ссылок для продуктов

## Проблема
При отправке ссылки на продукт (например `dostup.lovable.app/product/abc`) в мессенджерах показывается общее превью "Dostup" вместо названия, описания и картинки конкретного продукта. Это происходит потому, что мессенджеры не выполняют JavaScript и видят только статичные мета-теги из `index.html`.

## Решение
Создать серверную функцию (edge function), которая будет перехватывать запросы от ботов мессенджеров и отдавать HTML с правильными OG-тегами для каждого продукта.

## Как это будет работать

```text
Пользователь копирует ссылку
        |
        v
Отправляет в WhatsApp/Telegram
        |
        v
Бот мессенджера запрашивает URL
        |
        v
Edge Function "og-product"
        |
        v
Загружает данные продукта из базы
        |
        v
Возвращает HTML с мета-тегами:
  - og:title = "Название продукта"
  - og:description = "Описание продукта"
  - og:image = картинка продукта
        |
        v
Мессенджер показывает красивое превью
```

## Шаги реализации

### 1. Создать edge function `og-product`
Функция будет:
- Принимать `productId` как параметр
- Загружать данные продукта из базы (название, описание, картинка, цена)
- Возвращать минимальный HTML с правильными OG-тегами
- Включать JavaScript-редирект на основное приложение для обычных пользователей

### 2. Обновить `ShareLinkDialog`
Изменить формат генерируемой ссылки:
- Вместо прямой ссылки на SPA, генерировать ссылку через edge function
- Формат: `{SUPABASE_URL}/functions/v1/og-product?id={productId}&teacher={teacher}`
- Edge function отдаст правильные мета-теги ботам и перенаправит живых пользователей на приложение

### 3. Обновить `ProductPage`
- Добавить обработку параметров из редиректа edge function (на случай если параметры передаются через query string)

---

## Технические детали

### Edge Function `og-product`
- Получает `id` продукта из query params
- Делает запрос в таблицу `products` через service role
- Формирует HTML с мета-тегами: `og:title`, `og:description`, `og:image`, `og:url`
- Для обычных пользователей (не ботов) делает `<meta http-equiv="refresh">` редирект на `/product/{id}`
- Fallback на стандартные мета-теги если продукт не найден

### ShareLinkDialog
- Метод `generateLink()` будет возвращать URL через edge function вместо прямой ссылки на SPA
- Параметр `teacher` будет передаваться как дополнительный query param
