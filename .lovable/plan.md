

# Показать имена учителей в расписании ученика

## Что сделать

Рядом с названиями расписаний и в "Мои записи" показывать имя учителя или "Автор", чтобы ученик понимал к кому записывается и к кому записался.

## Изменения

### 1. `src/hooks/useSimplePurchases.ts` — useSimpleSchedules
После получения расписаний, подгрузить имена учителей из `simple_users` по `teacher_id`. Также подгрузить `creator_id` из `products` для отображения "Автор" у расписаний без учителя. Вернуть расписания с дополнительным полем `teacher_name`.

### 2. `src/hooks/useSimplePurchases.ts` — useSimpleBookings
Аналогично: при сборке данных бронирований подгрузить `teacher_id` из schedules и имена из `simple_users`. Добавить `teacher_name` в объект schedule.

### 3. `src/components/dashboard/ScheduleTab.tsx` — кнопки расписаний
Под названием каждого расписания показать мелким текстом имя учителя или "Автор" (если `teacher_id` отсутствует). Формат:
```
Индивидуальные уроки
Kamila Khairulla          ← мелкий серый текст
```

### 4. `src/components/dashboard/ScheduleTab.tsx` — "Мои записи"  
В карточках бронирований добавить имя учителя/автора рядом с типом занятия (group/individual).
