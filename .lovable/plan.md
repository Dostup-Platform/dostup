## Что делаем

Добавляем личные «звёздочки» к материалам и отдельную вкладку «Помеченные» внутри раздела Материалы. Автор может дополнительно делать пометки публичными — тогда у учеников рядом с их личной звездой появляется вторая иконка (звезда автора). Сверху в шапке материалов добавляется боковая панель разделов (справа), куда позже можно добавлять новые разделы.

## База данных

Новая таблица `material_bookmarks`:

- `material_id` (uuid → materials.id, on delete cascade)
- `user_type` (`creator` | `teacher` | `student`)
- `user_ref` (text — имя/айди в зависимости от роли, как в `support_threads`)
- `is_public` (bool, default false — имеет смысл только для creator; означает «показать ученикам как звезду автора»)
- `created_at`
- UNIQUE (material_id, user_type, user_ref)

GRANT, RLS включаем, политики:
- читать: либо своя строка (по user_type+user_ref), либо `is_public = true AND user_type = 'creator'`
- писать/удалять/обновлять: только свою строку
Так как у нас «псевдо-auth» (creator_token / SimpleAuth), политики делаем мягкие (доступ для `authenticated` и `anon` — как и остальные таблицы материалов), а проверки идентичности выполняем на клиенте через текущие хелперы. Это соответствует существующему паттерну в проекте (creator_sessions, simple_users и т.п.).

## UI — раскладка раздела Материалы

Текущий заголовок: поиск + фильтры слева, справа «Добавить материалы».

Новое:
- Текст кнопки везде: «Добавить» (убираем слово «материалы»). Затрагивает `CreatorMaterialsTab`, `ProductMaterialsManager`, `TeacherMaterialsTab`, `TeacherMaterialsManager`, `dashboard/MaterialsTab` — где такие кнопки есть.
- Desktop: поиск и фильтр сортировки сдвигаем максимально влево (чтобы не висели под боковой панелью). Справа под кнопкой «Добавить» — вертикальная боковая панель разделов:
  - Библиотека (активна по умолчанию)
  - Помеченные
  - (будущие разделы)
- Mobile: справа от кнопки «Добавить» — постоянная кнопка с тремя точками (`MoreVertical`), открывает `Sheet` с теми же разделами.

Разделы переключают содержимое раздела материалов; «Помеченные» показывают только помеченные пользователем материалы текущего продукта (область уже зависит от выбранного продукта вверху).

## UI — иконки на карточке материала

На каждой карточке материала справа добавляем:
- Личная звезда (`Star` / `StarOff`) — клик переключает свой буукмарк.
- Только у creator: вторая иконка «глаз»/«пользователи» рядом, видна только если личная звезда стоит — переключает `is_public` своей записи. Тултип: «Показать ученикам».
- У ученика/учителя: если у этого материала есть `is_public` creator-буукмарк — рядом с личной звездой показывается небольшая «звезда автора» (другой цвет, без клика, тултип «Отмечено автором»).

В контекстном меню (правый клик) добавляем пункт «Пометить / Снять пометку» как дубль.

## Вкладка «Помеченные»

В режиме «Помеченные»:
- Показываем плоский список (без папок) материалов, у которых есть моя bookmark-запись, текущего продукта.
- Для автора сверху переключатель «Показывать ученикам мои пометки» — массово выставляет `is_public=true/false` для всех его буукмарков текущего продукта (плюс возможность по одному переключать прямо в списке).
- Поиск работает так же.
- DnD/сортировка отключены (это виртуальный вид).
