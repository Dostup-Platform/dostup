### 2. `src/components/creator/ProductMaterialsManager.tsx`

Добавить пропс `mode: "add" | "edit"` (default `"edit"` для обратной совместимости).

**Режим `add`:**
- При открытии сразу `setIsAdding(true)` (форма добавления как сейчас — файл/папка/ссылка/текст, всё работает по-прежнему).
- Список существующих материалов **не отображается**.
- Кнопка верхнего уровня «Добавить материал/Добавить в папку» скрыта (форма уже открыта).
- После успешного сохранения (`handleAdd`) — закрывать диалог (`onClose()`) вместо возврата к списку.
- Кнопка «Отмена» в форме — закрывает диалог.

**Режим `edit`:**
- Форма добавления не показывается, кнопка «Добавить материал» скрыта.
- Показывается список материалов с действиями справа снизу: редактировать и удалить (как сейчас). Кнопки скачать/открыть для файлов и ссылок остаются.
- Клик по кнопке **«Редактировать» у папки** → вместо `handleEdit` вызывает `handleOpenFolder(material.id)` (открывает папку как при обычном клике по строке папки).
- Внутри открытой папки рядом с названием папки в breadcrumb/заголовке добавить маленькую иконку-кнопку **`Edit`** для переименования. Клик → открывает inline-форму переименования (Input + Save/Cancel), которая вызывает `updateMaterial` только с новым `title`. Никаких других полей.
- Клик по кнопке «Редактировать» у файла/ссылки/текста — работает как сейчас (открывает inline edit-форму с полями).
