

## Проблема
В хуке `useSimpleMaterials` не запрашивается поле `parent_id`, поэтому на стороне ученика невозможно понять, какие файлы находятся внутри папки. Все материалы (папки и их содержимое) отображаются плоским списком.

## Решение

### 1. `src/hooks/useSimplePurchases.ts` — добавить `parent_id` в select
В обоих запросах материалов (creator и teacher) добавить `parent_id` в список полей.

### 2. `src/components/dashboard/MaterialsTab.tsx` — иерархическое отображение
- Фильтровать материалы: показывать только корневые (`parent_id` is null)
- Для папок (`type === "folder"`) — сделать их кликабельными (collapsible)
- При клике на папку — показать дочерние материалы (у которых `parent_id === folder.id`)
- Использовать состояние `expandedFolders: Set<string>` для отслеживания открытых папок
- Дочерние материалы отображать с отступом внутри папки

### Визуальная структура
```text
┌─ 📁 Папка (кликабельна) ──────────┐
│  ├─ 📄 Файл 1                     │
│  ├─ 📄 Файл 2                     │
│  └─ 📄 Файл 3                     │
└────────────────────────────────────┘
```
