

# Увеличить точки-индикаторы на мобильных устройствах

## Проблема
Точки уже есть в коде всех трёх компонентов (автор, учитель, ученик), но при размере `w-2 h-2` (8px) они слишком мелкие для мобильных экранов и практически незаметны.

## Решение
Сделать точки адаптивными: на мобильных — `w-2.5 h-2.5` (10px), на десктопе — оставить `w-2 h-2` (8px). Используем Tailwind responsive классы.

## Изменения (3 файла)

### 1. `src/components/creator/CreatorScheduleTab.tsx`
Строка 793: заменить `w-2 h-2` на `w-2.5 h-2.5 sm:w-2 sm:h-2`.

### 2. `src/components/teacher/TeacherScheduleTab.tsx`
Строка 844: заменить `w-2 h-2` на `w-2.5 h-2.5 sm:w-2 sm:h-2`.

### 3. `src/components/dashboard/ScheduleTab.tsx`
Строка 478: заменить `w-2 h-2` на `w-2.5 h-2.5 sm:w-2 sm:h-2`.
