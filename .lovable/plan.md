

# Замена крестика рядом с именем ученика на диалог причин при удалении слота

## Что сейчас
- Рядом с именем каждого записавшегося ученика стоит кнопка X (крестик) для отмены конкретной записи
- При нажатии кнопки "Удалить слот" (Trash2) для слота с записями показывается простое подтверждение "Удалить слот с записями?"

## Что нужно
1. **Убрать крестик (X)** рядом с именем ученика — оставить только имя без кнопки удаления
2. **При нажатии кнопки удалить (Trash2)** на слоте:
   - Если ученик **не записался** — показать простое подтверждение "Вы точно хотите удалить слот?" (как сейчас)
   - Если ученик **записался** — показать `CancellationReasonDialog` с выбором причин и комментарием перед удалением

## Изменения

### Файл 1: `src/components/creator/CreatorScheduleTab.tsx`

1. **Убрать крестик** — удалить блок кнопки X рядом с именем ученика (строки 962-969), оставить только имя
2. **Заменить диалог удаления слота с записями** (строки 1213-1234) — вместо простого AlertDialog использовать `CancellationReasonDialog` для `deletingSlotWithBookings`. При подтверждении вызвать `deleteSlotWithBookings.mutate()` и передать причины/комментарий (cancel all bookings + delete slot)

### Файл 2: `src/components/teacher/TeacherScheduleTab.tsx`

Аналогичные изменения:

2. **Заменить диалог удаления слота с записями** (строки 1265-1286) на `CancellationReasonDialog`

### Техническая деталь

При подтверждении в `CancellationReasonDialog` для удаления слота с записями — сначала записать причины отмены в `booking_cancellations` для каждой записи на этом слоте, затем удалить записи и слот. Нужно будет модифицировать `deleteSlotWithBookings` мутацию чтобы принимать reasons/comment и создавать записи в `booking_cancellations`.
